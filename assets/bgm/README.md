# Brick King BGM assets

All four tracks are downloaded from OpenGameArt and marked CC0 on their source pages.
They are stored locally so the game does not require a network connection while playing.

| Local file | Display name | Source |
| --- | --- | --- |
| `8bit-focus.mp3` | Pixel Focus | https://opengameart.org/content/8-bit-concentration-loop |
| `8bit-amusement.ogg` | Arcade Rush | https://opengameart.org/content/amusement-park-stage |
| `slot-bonus.mp3` | Bonus Fever | https://opengameart.org/content/cc0-retro-music |
| `slot-summer.ogg` | Lucky Summer | https://opengameart.org/content/summer-park-8bit-tune-loop |

License: CC0 / Public Domain. The display names in the game are custom labels; the source page names are listed above.
